# Speable desktop releases

Public installers and signed update files for Speable Desktop. The application source is maintained separately.

This repository is the update source for the direct-download app. Releases are published here after validation; there is no public stable release yet.

The app checks for updates automatically and lets you choose when to install and restart. Update downloads are verified with Speable’s updater signing key. Never install an update offered outside the app or this repository.

Mac App Store builds will receive updates through the App Store instead.
